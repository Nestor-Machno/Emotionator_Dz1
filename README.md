 # Эмоционатор (AR Emotion System)

**Эмоционатор** — это интерактивное десктопное приложение для распознавания лиц и анализа эмоций в реальном времени. 

**Как посмотреть приложение**: перейти по ссылке 'https://emotionator-dz1.onrender.com/'

## 🏗 Архитектура
* **Сервер (Backend):** FastAPI (Python) + OpenCV (FaceDetectorYN) + ONNX Runtime (FERPlus). Сервер выполняет всю тяжелую работу по инференсу нейросетей.
* **Frontend:** Легкий веб-интерфейс (HTML/JS/CSS), который запрашивает доступ к камере в браузере и обменивается кадрами с сервером по WebSocket.

## 🔄 Описание CI/CD процесса

Весь процесс автоматизирован через GitHub Actions (`.github/workflows/ci-cd.yml`) и локальные bash-скрипты.

1. **Хранение исходного кода:** Код приложения, статические файлы и модели нейросетей лежат в Git-репозитории.
2. **Сборка (Build):** При каждом пуше в ветку `main` (или при ручном запуске скрипта `build.sh`) исходники упаковываются в единый версионированный релизный артефакт (`.tar.gz`).
3. **Сохранение артефакта:** В облаке GitHub артефакт автоматически сохраняется во вкладке **Actions -> Artifacts**. При локальном запуске он сохраняется в директорию `artifacts/`.
4. **Упаковка и Деплой (Package & Deploy):** Скрипт `deploy.sh` (или Docker-среда хостинга) берет готовый собранный артефакт, распаковывает его внутри `Dockerfile`, устанавливает зависимости и поднимает Docker-контейнер. Облачный хостинг Render автоматически обновляет приложение при получении вебхука об успешной сборке.

## 🚀 Как запустить проект (для проверки)

Проект содержит bash-скрипты для полного цикла локального развертывания на Linux-системах.

1. Выдайте права на исполнение скриптам:
   ```bash
   chmod +x build.sh deploy.sh
   ```
2. Соберите артефакт приложения:
   ```bash
   ./build.sh
   ```
   *(Скрипт создаст папку `artifacts` и положит туда релизный `.tar.gz` архив).*
3. Упакуйте артефакт в Docker-контейнер и запустите его:
   ```bash
   ./deploy.sh
   ```
   *(Скрипт соберет Docker-образ на основе артефакта и поднимет контейнер на порту 8000).*

## 📊 Мониторинг и Метрики

В приложение встроена система мониторинга, отслеживающая 3 обязательные метрики.
Дашборд мониторинга доступен по адресу: `https://emotionator-dz1.onrender.com/monitoring`

**Отслеживаемые метрики:**
1. **Health check (Работоспособность):** Проверка статуса сервера `200 OK`, времени непрерывной работы (Uptime) и успешности загрузки весов ONNX-моделей в память. Доступен как отдельный эндпоинт `https://emotionator-dz1.onrender.com/health`.
2. **Метрика ресурсов:** Мониторинг потребляемой и доступной оперативной памяти (RAM) сервера, загрузки CPU и свободного места на диске в реальном времени (через библиотеку `psutil`).
3. **Бизнес-метрика использования:** Счетчик количества уникальных загрузок клиента и количества успешно распознанных кадров **за последний час** (и за всё время работы контейнера).

**Сырые данные метрик (JSON):** `https://emotionator-dz1.onrender.com/api/v1/metrics`
