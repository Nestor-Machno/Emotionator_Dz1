 # Эмоционатор (AR Emotion System)

**Эмоционатор** — это интерактивное десктопное приложение для распознавания лиц и анализа эмоций в реальном времени. Проект объединяет быстрый backend на Python с нейросетевыми моделями и красочный интерфейс с уникальными кастомными пиксельными ассетами и анимациями.

---


## ✨ Ключевые особенности

*   **Анализ в реальном времени:** Использование моделей обнаружения лиц (YuNet) и классификации эмоций (FERPlus) через `ONNX Runtime` для обеспечения высокой скорости работы (Inference).
*   **Современный стек:** Backend построен на `FastAPI`, а обмен кадрами и результатами между сервером и клиентом происходит без задержек по протоколу `WebSocket`.
*   **Трекинг лиц:** Кастомный алгоритм трекинга (с использованием Intersection over Union и EMA-сглаживания) для стабильного отображения эмоций без мерцания.
*   **Геймифицированный UI:** Разработанный с нуля frontend-интерфейс (HTML/CSS/JS) запускается в нативном окне с помощью `pywebview`. Включает систему интерактивного обучения с анимированным маскотом (Обл), детальный дашборд статистики и динамические реакции на эмоции пользователя.

---

## 🛠 Технологический стек

**Backend:**
*   Python 3.x
*   [FastAPI](https://fastapi.tiangolo.com/) & Uvicorn (REST & WebSocket API)
*   [OpenCV](https://opencv.org/) (Обработка изображений, CLAHE эквализация)
*   [ONNX Runtime](https://onnxruntime.ai/) (Запуск моделей машинного обучения)

**Frontend:**
*   HTML5 / CSS3 / Vanilla JavaScript
*   `pywebview` (Для рендеринга web-интерфейса в десктопном окне)
*   WebRTC (Захват потока с веб-камеры)

##  Как установить и запустить (Для пользователей)

Если вы просто хотите протестировать Эмоционатор без установки Python и работы с кодом, вы можете скачать готовую программу:

1. Перейдите в раздел **[Releases](https://github.com/Nestor-Machno/Emotionator/releases)** (находится в правой части страницы GitHub).
2. В самом верхнем (последнем) релизе найдите раздел **Assets** и скачайте файл установщика (например, `Emotionator.exe`).
3. Запустите скачанный файл.
4. Готово! Программа установлена, и вы можете запускать её через ярлык.

*Примечание: Поскольку программа разработана инди-командой и не имеет дорогого цифрового сертификата, встроенный защитник Windows (SmartScreen) может выдать предупреждение при первом запуске. Это нормально. Просто нажмите «Подробнее» -> «Выполнить в любом случае».*
##  Установка и запуск (Для разработчиков)

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/](https://github.com/)[ТВОЙ_НИКНЕЙМ]/Emotionator.git
   cd Emotionator

2. **Создайте виртуальное окружение и активируйте его:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для Linux/Mac:
   source .venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Скачайте нейросетевые модели:**
   *Убедитесь, что файлы `face_detection_yunet_2023mar.onnx` и `emotion-ferplus-8.onnx` находятся в папке `models/`*

5. **Запустите приложение:**
   ```bash
   python bacend.py
   ```
